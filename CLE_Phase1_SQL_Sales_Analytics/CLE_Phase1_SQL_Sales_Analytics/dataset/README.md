# Dataset

This project uses synthetic sample records inserted by `sql/02_load_sample_data.sql`.

The data is intentionally small so you can inspect joins and window-function results easily. It is not a downloaded Kaggle dataset and should not be represented as one. For the roadmap's public-dataset activity, download a public e-commerce dataset (for example, Olist) separately and map its fields into the project schema before loading it.
