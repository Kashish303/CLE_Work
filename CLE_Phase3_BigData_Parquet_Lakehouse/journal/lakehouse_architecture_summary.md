# Learning Journal – Databricks Lakehouse Architecture

**Source read:** Databricks, “What Is a Lakehouse?”  
https://www.databricks.com/blog/what-is-data-lakehouse

A lakehouse combines the low-cost, flexible storage of a data lake with the data management and reliability features of a data warehouse.  
It keeps data in open formats such as Parquet while adding a metadata/transaction layer through technologies such as Delta Lake.  
This supports capabilities such as ACID transactions, schema enforcement, time travel, and governance for analytics and machine learning.  
The architecture helps teams work on shared data without maintaining separate lake and warehouse copies.

**My takeaway:** A lakehouse aims to provide one reliable and open data platform for data engineering, BI, data science, and machine learning.
